variables

Variables

A variable is a named container for a value. JavaScript gives you three ways to declare one, and the difference between them is about scope and whether the value can change.

  • let — can be reassigned later, scoped to the block it's declared in.
  • const — cannot be reassigned; use it by default unless you know the value will change.
  • var — the older way, function-scoped instead of block-scoped. Mostly avoided in modern code.

Naming convention: camelCase, starting with a letter — firstName, not first_name or 1stName.

variables
let score = 0;
score = score + 10;    // 10, reassigned

const maxPlayers = 4;
// maxPlayers = 5;  ❌ error — const can't change

var oldStyle = "still works, rarely used";
data-types

Data types

Every value in JavaScript has a type. The primitive types hold a single value; objects hold collections of values.

  • String — text, wrapped in quotes: "hello"
  • Number — integers and decimals: 42, 3.14
  • Boolean — true or false
  • Undefined — a variable declared but not yet given a value
  • Null — an intentional "nothing"
  • Object — a structured collection, including arrays and functions

Use typeof to check what type a value is at any point in your script.

data-types
typeof "hello";      // "string"
typeof 42;           // "number"
typeof true;         // "boolean"
typeof undefined;    // "undefined"
typeof null;         // "object" (a known quirk)
typeof {};           // "object"
functions

Functions

Functions are blocks of code designed to perform a particular task, executed when something calls them.

  • Declaration — function name() {}, hoisted to the top of its scope
  • Expression — const name = function() {}, assigned to a variable
  • Arrow function — const name = () => {}, concise syntax, doesn't bind its own this
functions
function greet(name) {
  return `Hi, ${name}`;
}

const greetV2 = function(name) {
  return `Hi, ${name}`;
};

const greetV3 = (name) => `Hi, ${name}`;

greet("Arve");  // "Hi, Arve"
arrays

Arrays

An array is an ordered list of values, indexed starting at zero. It can hold any data type, including other arrays.

  • push / pop — add or remove from the end
  • shift / unshift — add or remove from the start
  • map — build a new array by transforming each item
  • filter — build a new array of items that pass a test
arrays
const topics = ["variables", "types", "functions"];

topics.push("arrays");
// ["variables", "types", "functions", "arrays"]

topics[0];  // "variables" — first item, index 0

const shouted = topics.map(t => t.toUpperCase());
objects

Objects

An object stores data as key-value pairs. It's how you group related information — and behavior — into one structure.

  • Access values with dot notation (obj.key) or bracket notation (obj["key"])
  • Objects can hold functions as values — these are called methods
  • Inside a method, this refers to the object it belongs to
objects
const course = {
  title: "JavaScript Basics",
  weeks: 2,
  describe() {
    return `${this.title} — ${this.weeks} weeks`;
  }
};

course.describe();
// "JavaScript Basics — 2 weeks"
